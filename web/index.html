Il telefono Android virtuale gira su GitHub Actions. Da Safari puoi aprire il pannello dei test, avviare il workflow e vedere gli screenshot prodotti.

Apri test Android
  1. Apri Run workflow.
  2. Inserisci l'URL diretto dell'APK da testare.
  3. Premi Run workflow.
  4. Al termine apri il run e scarica android-test-results.
